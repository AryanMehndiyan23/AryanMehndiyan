# Campus Expense Tracker

## 1. Problem Statement

Managing daily campus expenses manually can be difficult when there are many expenses. It can take time to check the total amount spent and to find which category has the highest spending.

This project provides a simple Python program that allows users to add, view and analyze campus expenses. It helps calculate total spending, category-wise spending and the highest spending category.

## 2. Scope of the Project

The project is designed for basic campus expense tracking and analysis.

It can be used to:

- Add expenses with an expense name, category and amount.
- View all recorded expenses.
- Calculate total spending.
- Calculate spending for each category.
- Find the category with the highest spending.
- Display the results through a simple command-line menu.

The current project stores expenses only while the program is running and does not use permanent storage or a database.

## 3. Target Users

The main target users are:

- Students who want to track their campus expenses.
- Beginners learning Python programming.
- Users who want a simple way to analyze their spending.

## 4. High-Level Features

- Add Expense
- View Expenses
- Total Spending Calculation
- Category-wise Spending
- Highest Spending Category
- Simple menu-based interface
- No external libraries required
